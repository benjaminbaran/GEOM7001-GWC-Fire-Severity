# GEOM7001 – Green Wattle Creek fire severity

DEA Sandbox Jupyter notebook for the GEOM7001 project report.

The notebook loads Sentinel-2 Collection 3 ARD, calculates NBR, dNBR, RdNBR and RBR, applies literature and local FESM-median thresholds, and trains a scene-specific Random Forest. NSW FESM 2019/2020 is the reference.

Open the `.ipynb` file in this repository to view the full analysis and data processing log.
